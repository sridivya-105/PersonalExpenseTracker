\\ Personal Expense Tracker



A desktop-based expense tracking application developed using Java Swing. It helps users record expenses, organize them into categories, and monitor spending through a graphical user interface.



\\ Features



\- Add and record personal expenses.

\- Organize expenses into categories:

&#x20; - Personal

&#x20; - Groceries

&#x20; - Bills \& Fees

&#x20; - Shopping

\- View the total amount spent in each category.

\- Filter expenses by category.

\- View all recorded expenses in one place.

\- Calculate the overall expenses total.



\\ Technologies Used



\- Java

\- Java Swing

\- Object-Oriented Programming



\\ Prerequisites



\- Java Development Kit (JDK) installed.

\- A terminal or command prompt.



\\ How to Run



1\. Clone or download this repository.

2\. Open a terminal in the project directory.

3\. Compile the Java source code:



&#x20;  javac Main.java

&#x20;



4\. Run the application:





&#x20;  java Main
